# SARIF Specification Decisions

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT",
"SHOULD", "SHOULD NOT", "RECOMMENDED", "NOT RECOMMENDED", "MAY", and
"OPTIONAL" in this document are to be interpreted as described in BCP 14
[RFC2119] [RFC8174] when, and only when, they appear in all capitals, as
shown here.

This register governs the observable SARIF emitted by `analysis.WriteSARIF`
and `golib-analysis check -format sarif`. It does not claim that the package
implements every optional SARIF object. The source matrix and maintained-peer
review live under [`specification/`](../specification/README.md).

Every resolved entry retains its exact typed record below so human and machine
review cannot silently diverge. The authoritative specification is
<https://docs.oasis-open.org/sarif/sarif/v2.1.0/os/sarif-v2.1.0-os.pdf>.

## ANALYSIS-SARIF-DEC-001: Document version and schema identity

The package selects one stable SARIF version and records its deliberate schema
mirror choice, source monitoring, compatibility boundary, and maintained-peer
comparison.

Authoritative source: <https://docs.oasis-open.org/sarif/sarif/v2.1.0/os/sarif-v2.1.0-os.pdf>.

Authoritative source: <https://docs.oasis-open.org/sarif/sarif/v2.1.0/os/sarif-v2.1.0-os.pdf>.

## ANALYSIS-SARIF-DEC-004: Locations, paths, and source omission

Command output stays inside the official location profile. Direct callers must
supply valid text positions; the writer does not invent repaired locations.

Authoritative source: <https://docs.oasis-open.org/sarif/sarif/v2.1.0/os/sarif-v2.1.0-os.pdf>.


## ANALYSIS-SARIF-DEC-005: Exception and suppression extension properties

Policy audit inventories remain run extensions because they are not equivalent
to suppressions attached to emitted SARIF results.

Authoritative source: <https://docs.oasis-open.org/sarif/sarif/v2.1.0/os/sarif-v2.1.0-os.pdf>.
