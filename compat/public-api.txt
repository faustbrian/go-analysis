## github.com/faustbrian/go-analysis/analysis

package analysis // import "github.com/faustbrian/go-analysis/analysis"

Package analysis owns strict policy configuration, rule metadata, attributable
suppressions and deterministic JSON/SARIF 2.1.0 reporting. LoadConfigContext
or ParseConfigBytes produces a policy snapshot; analyzer-specific constructors
validate their own options. This package does not load or execute target code.

Exported records are mutable and caller-owned. Do not mutate shared maps,
slices or records during validation/reporting. Writers borrow their output and
copy outer report slices, not nested rule metadata; no callback or IO lifecycle
is retained. Omitting source/snippet fields is not arbitrary-text redaction:
configured attribution, diagnostic messages and underlying errors remain data
the caller must govern. Parser byte limits are not a process-memory budget.

FUNCTIONS

func ApplyPolicyExceptions(
	root string,
	diagnostics []Diagnostic,
	exceptions []PolicyException,
	now time.Time,
) ([]Diagnostic, []PolicyException, error)
    ApplyPolicyExceptions filters exact rule/package and optional normalized
    file matches. Expiry is inclusive through its UTC date; attribution and
    prior Used flags are not authenticated or reset. Use freshly validated
    configuration. First matching entry wins; unused entries fail with nil
    findings and an updated copied inventory. Errors can also return that
    inventory. Inputs are not mutated; with no exceptions the original
    diagnostics slice is returned unchanged.

func ApplySuppressions(
	diagnostics []Diagnostic,
	suppressions []Suppression,
) ([]Diagnostic, []Suppression, error)
    ApplySuppressions filters exact rule/filename/target-line matches and
    updates a copied inventory. It does not revalidate directive syntax,
    expiry or prior Used flags; normally pass a freshly parsed inventory.
    Duplicate inputs use the first match. An unused entry returns nil findings,
    the updated inventory and an error. Inputs are not mutated; retained
    findings use a new outer slice.

func WriteJSON(writer io.Writer, report Report) error
    WriteJSON emits a newline-terminated report with sorted outer inventories
    and normalized diagnostic/suppression paths. It omits source/snippet fields,
    but caller messages, attribution, metadata and exception Path remain
    unsanitized. Validation precedes writing; writer errors may leave partial
    output. The writer is borrowed, must be non-nil, and is never flushed or
    closed. Nested rule maps remain shared with the input; do not mutate them
    during serialization. No byte or entry limit is enforced here.

func WriteSARIF(writer io.Writer, report Report) error
    WriteSARIF emits newline-terminated SARIF 2.1.0 with sorted inventories,
    relative diagnostic/suppression paths and no source/snippet fields.
    It shares WriteJSON's borrowed-writer, partial-output, mutation and
    arbitrary-text limits. Unknown diagnostic rule IDs receive warning level
    rather than being rejected; metadata and SARIF schema conformance are not
    validated by this writer.

func LoadConfig(path string, knownRules []string) (*Config, error)
    LoadConfig reads exactly one strict YAML policy document.

    Deprecated: use LoadConfigContext for cooperative filesystem cancellation.

func LoadConfigContext(
	ctx context.Context,
	path string,
	knownRules []string,
) (*Config, error)
    LoadConfigContext reads exactly one strict YAML policy document. It
    observes cancellation before and around file reads and does not retain ctx.
    A blocked os.Open/Read and buffered YAML decoding are not preempted.
    The file is closed on return; up to 1 MiB of configuration is admitted.
    ctx must be non-nil.

func ParseConfigBytes(path string, contents []byte, knownRules []string) (*Config, error)
    ParseConfigBytes validates one bounded strict YAML policy snapshot. The path
    determines the root for repository-relative configuration and is not read.
    Input above 1 MiB, unknown YAML fields, multiple documents or invalid shared
    policy are rejected with nil configuration. YAML decoding can allocate
    before semantic validation; this byte cap is not a total memory/CPU budget.
    Contents and knownRules are borrowed only during the call; the decoded
    records are new.

func (config Config) Validate(knownRules []string) error
    Validate checks shared policy structure against governed IDs without
    mutation. It does not authenticate promotion evidence, check file
    existence/generated headers, or validate every analyzer-specific typed
    policy. A nil knownRules list permits no explicit rule override or exception
    IDs.

func ParseSuppressions(
	fset *token.FileSet,
	file *ast.File,
	knownRules []string,
	now time.Time,
) ([]Suppression, error)
    ParseSuppressions reads exact //analysis:ignore directives from parsed
    comments. Rules must be known; reason is required, metadata keys may not
    repeat, and expires uses an inclusive UTC calendar date. TargetLine follows
    group.End, including other comments in that group. Malformed or duplicate
    target/rule directives return nil inventory and an error. file/fset must be
    non-nil and consistent. The parser borrows them without mutation and has no
    size limit.
